# 05 · v3 实现契约（Lead 与 4 位开发共用）

> 本文件是 v3 重做的**唯一接口契约**。所有模块严格按这里导出的签名实现；签名不符导致的集成失败由该模块负责人修。
> 数值只从 `src/data/balance.json`（经 `src/data/balance.ts` 访问器）与 `src/data/characters.ts` 读，**不要在代码里写死数值**。

## 0. 用户拍板的 v3 规则（m00597）

1. **删掉回旋刃**（自动武器）：玩家改为主动操作 —— 鼠标左键点击普攻、右键技能。
2. **取消经验/等级系统**：没有经验豆、没有升级三选一。所有成长用金币在商店购买专属装备（专武）与增益卡。
3. **怪物数量固定**：每层怪物总数固定（`quotaFor(layer)`），刷完即止，不再无限刷新。
4. **无倒计时**：每层清完固定数量怪物即过关；不设超时判负，只有血量归零会失败。
5. **奖励房收益高于对战房**：奖励房给宝箱金币（显著多于战斗房）或技能卡。
6. **新增存档/读档**：每层开始自动存档，暂停菜单可手动存/读，标题页可继续游戏；3 个槽位 localStorage。
7. 金币与充能全部来自击杀（充能还能靠层间 50% 起手与部分奖励）。

## 1. 全局约定

- 单位米。坐标：x 向右、z 向后；相机 yaw=0 时看向 -z；地面 y=0，实体脚底贴地。
- 相机约定（不可改）：`相机位置 = 玩家 + (sin(yaw)*dist, height, cos(yaw)*dist)`，屏幕 W = 世界 `(-sin, -cos)`。`Player.update(dt, moveX, moveZ, cameraYaw, colliders, bounds)` 的 moveX/moveZ 是**屏幕系输入**。
- 公式（唯一口径，见 `src/data/characters.ts`）：
  - 攻击间隔 = `max(minInterval, 0.55 * 100 / 耐力)`
  - 单次伤害 = `武器基础伤害 * 魔力 / 100`（暴击再乘 critMultiplier）
  - 射程/半径 = `武器基础范围 * 智力 / 100`
- 命中接口统一为 `Hittable`（见 §2）。**击杀的结算（金币、充能、计数、掉落、飘字、音效）只在 `game.ts` 做**，武器/弹道/召唤物只负责调 `hit()` 并上报。
- 不改 `package.json`、`tsconfig.json`、`vite.config.ts`；不新增依赖；不引入外部图片/字体/CDN。
- 只修改自己归属的文件（见 §6）。需要别人改，先给 Lead 发消息。
- **禁止用 PowerShell 管道改写源码**（会毁 UTF-8 中文），只用 write/edit 工具。
- 中文注释可以，但不写长篇说明；关键数值/坑点写一行注释即可。
- 自测：`npx tsc --noEmit` 必须通过（别人未完成的文件导致报错时，注明是哪个文件）；提交前把 `npx tsc --noEmit` 结果写进汇报。

### 必须导出的类型与类（`src/systems/combat.ts`）

```ts
export interface Hittable {
  x: number; z: number; radius: number; alive: boolean
  /** 返回是否被这一下打死 */
  hit(amount: number, kx: number, kz: number): boolean
}

export interface CombatWorld {
  enemies: Hittable[]
  halfSize: number
  clamp(x: number, z: number): { x: number; z: number }
  heal(n: number): void
  grantInvuln(seconds: number): void
  /** 丛雨突进：把玩家沿方向瞬移/推进 distance 米，duration 秒，期间无敌 */
  dashPlayer(dirX: number, dirZ: number, distance: number, duration: number): void
  burst(x: number, z: number, color: number, count?: number): void
}

export interface CombatHooks {
  onHit(t: Hittable, amount: number, crit: boolean, killed: boolean): void
  onSfx(name: 'attack' | 'crit' | 'skill' | 'summon' | 'dash'): void
}

export class Combat {
  constructor(scene: import('three').Scene, hooks: CombatHooks)
  setCharacter(id: CharacterId): void
  /** 专武等级 1..5（购买后由 game.ts 调用；换层保留） */
  setWeaponLv(level: number): void
  get weaponLv(): number
  get charge(): number
  get chargeMax(): number
  get chargeRatio(): number
  get skillName(): string
  get skillReady(): boolean
  /** 变身期间的临时五维修正，game.ts 每帧乘进面板（未变身返回全 1 / 0） */
  get modifiers(): {
    staminaMul: number
    magicMul: number
    intelligenceMul: number
    moveSpeedMul: number
    damageReduction: number
  }
  /** 点击左键，内部按攻速节流；返回本次是否真的出手 */
  tryAttack(dt: number, px: number, pz: number, aimX: number, aimZ: number, world: CombatWorld): boolean
  /** 右键；充能不足返回 false */
  trySkill(px: number, pz: number, aimX: number, aimZ: number, world: CombatWorld): boolean
  /** 敌人死亡时调用：加充能（CHARGE_PER_KILL * (1 + chargeGain)） */
  onKill(t: Hittable): void
  /** 每帧推进：弹道、召唤物、Mortis 脉冲、变身计时、突进残影 */
  update(dt: number, px: number, pz: number, world: CombatWorld): void
  get transformActive(): boolean
  dispose(): void
}
```

`src/systems/charge.ts` 导出 `ChargeMeter`（value/max/reset(max, startRatio)/add(n)/spend/ratio/ready）。
`src/data/characterRuntime.ts` 导出 `getWeaponTier(charId, level)`（读 `balance.json` 的 `weapons`）与 `charTakeDamageMul(charId)`（若叶睦 1.0、丛雨 1.45、肥鱼 0.85 —— 与模拟器口径一致，丛雨近战吃亏）。

### 行为要求

- **若叶睦**：左键投掷小黄瓜（弹道，单体，lv4 起弹射、lv5 变大+弹射），Mortis 变身 8s（攻速/伤害↑、范围↓、移速×0.9、减伤 0.15），变身瞬间半径爆发+击退，之后每 0.5s 一圈音波脉冲（半径 = `pulseBaseRadius * 智力/100`）。专武 lv3 起 Mortis 吸血（伤害 8% 回血），lv4/5 变身期间普攻改成向前音波剑气（可贯穿、lv5 弹射）。
- **丛雨**：左键扇形 110° 拔刀，一次最多命中 8 个目标（近战 AoE 的核心爽点），射程 `3.0 * 智力/100`；lv2 起普攻带聚怪（命中把敌人拉向玩家 0.35m），lv4 起普攻带前冲 0.9m。右键 突进：7.5m/0.24s、路径宽 1.8m 造成伤害、终点 2.4m 内敌人拉向终点、回血 15（命中≥3 额外 +5）、无敌 0.3s、结束 0.2s 硬直。
- **肥鱼**：左键水枪泡泡（弹道，单体；lv2 起穿透 1、lv3 起每 10s 掉一颗白米饭「拾取回 20 充能」、lv5 泡泡更大+穿透 2）；右键 召唤小肥鱼（3 只，专武 lv5 5 只），继承 35% 生命、0.6s 一发 40% 伤害的泡泡，跟随玩家 5m 内、持续 10s（重复释放刷新）。小肥鱼会被哥布林打（有独立血量），死亡消失。
- 弹道必须有可见像素贴图（`src/art/projectiles.ts` 程序化 Canvas：黄瓜 8×4 绿、泡泡 10×10 半透明蓝、音波 24×24 紫），命中爆粒子走 `world.burst`。
- 攻击/技能 CD、充能、变身时间都在 `Combat` 内部计时；`game.ts` 只负责传输入和 `CombatWorld`。
- 全部伤害走 `hit()`，暴击率/倍率从玩家面板取（`PlayerStats.critChance/critMultiplier`，v3 基础 8%/1.8）。暴击时 `onSfx('crit')`。

### 规则
- 隧道三扇门：`weights` 从 `balance.portals`；**类别可重复**；所有非最后一层战斗房 50% 怪潮/50% 精英，最后一层 Boss 房 100%；房间内再掷宝箱/技能卡、商人/祭坛。
- 奖励房金币显著高于战斗房（用 `balance.portals.chestGoldBase/chestGoldPerLayer` × 1.0，战斗房按 `mobWaveGoldMul/eliteFightGoldMul` 的对照值；具体乘法按 balance 字段实现，不要自己编）。
- 商店 4 格 + 重掷 25 金；增益卡价格与品质随层数提高（`shopPriceFor` + `rollQuality`）；专武升级按角色当前等级出售（只能升下一级，购买后立即生效，不进入背包）。
- 背包：12 格；两张**同级同种增益卡**合成下一级，数值×2，最高 3 级；卡片进背包即计入面板（`cards` 由 `Inventory` 汇总）。
- 存档：localStorage key 用 `balance.save.storageKey`；存的就是 `RunState`（types.ts 已定义）；读档时校验 `version`，坏档返回 null 并删除。

## 4. UI（owner: ui）

### 归属文件
`src/ui/hud.ts`、`src/ui/dom.ts`、`src/styles.css`（`index.html` 若需加容器节点，先问 Lead）。

必须实现 `types.ts` 的 **`HudV3`**（`createHud(handlers: HudV3Handlers): HudV3`），`game.ts` 只依赖这个接口。方法语义：

- `showTitle(slots)`：标题页；含难度三卡 + 角色三卡（选角色）+「开始爬塔」，以及可「继续游戏」（有存档时列出槽位）。
- `showCharacterSelect()/hideCharacterSelect()`：保留方法，可做标题页内的切换态。
- `showTunnelOffers(offers, layer, mode?)`：`mode='bonus'` 为清层奖励卡三选一（暖金/礼物/STEP 1/2），`mode='tunnel'` 为层末三扇门三选一（冷青/罗盘/STEP 2/2）；显示类型（奖励/交易/对战）、房间名、奖励预览（金币数、卡名、敌人数量）。
- `showShop/updateShop/hideShop`：4 格商品、金币、重掷按钮、进入背包、继续。
- `showInventory/updateInventory/hideInventory`：12 格 + 已获卡片汇总（五维）+ 合成/使用操作说明。
- `showPause(slots)` / `showSaveSlots('save'|'load', slots)`。
- `showDefeat(reason, stats)`（reason 目前只有 `hp` 血尽）、`showVictory(stats)`。
- `showLayerBanner(layer, name, subtitle, total)`。
- `update(snapshot: HudSnapshot)`：HUD 常驻信息。v3 快照字段见 types.ts —— **XP/等级不再显示**，改为：金币、层数/阶段、难度、本层进度 `monsterKilled/monsterTotal`、生命、**技能充能条 + 技能名 + 专武 Lv**、Boss 条、场上敌人数。
- `damageNumber/setCamera`：保留（飘字投影）。
- 视觉沿用现有深色玻璃拟态 + 琥珀/青绿霓虹风格；**仅桌面浏览器 + 键鼠**，移动端/触屏不做；窄屏只保证 UI 能看能点、不崩。
- 字体、图标全部用 CSS/内联；不引入外部资源。
