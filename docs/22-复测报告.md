## 3. 数据异常声明（自动机缺陷，非游戏 bug）

3 局出现异常游戏内时长（1.0万~2.9万秒），对应「timeout 到达终层」的局：
自动机在快进下于某处循环徘徊（疑似 Boss 门/休憩房决策死循环），游戏本体逻辑未复现卡死。
真人试玩不存在此路径。这三局的「时长」列不可作为平衡依据。

## 4. 建议（按优先级）

1. **P1-1' Boss 前补给窗**：首领门开启前若玩家血量 <50%，在 Boss 房门口刷一个
   营地祭坛（一次性回血 30%）——对应 docs/21 §8「进 Boss 时经常 50% 血以下」。
2. **睦的生存兜底**：睦（110 HP、无自回）在普通/困难全部最先死；
   候选：Q/F 解锁前置的节点需求从 2 降为 1，或给睦基础 HP +10。
   两者都动机制，等真人试玩后再拍板。
3. **自动机 stall**：下轮复测前修 playtest-matrix 的徘徊检测（同房间停留 >120s 判超时并记录现场）。
4. **数值不动**：流程与接线修复后数据已明显改善，在真人试玩前不再调参。
