# 招式特效提示词 · v1

> 用途：重做全部招式特效（现版本是"能看出发生了什么"，但不够二次元、不够亮、招式之间辨识度低）。
> 本文给的是**素材生成提示词 + 落地参数**，可直接喂给图像模型出图，再走 `scripts/art-normalize.py` 归一化。

## 0. 统一规范（所有特效都遵守）

| 项 | 规范 |
| --- | --- |
| 画风 | 明亮二次元 / 像素描边 / 高饱和 + 白色内芯，**不要写实、不要烟雾写实纹理** |
| 混合 | 全部 `AdditiveBlending`，`toneMapped: false`（否则会被场景色调压灰） |
| 配色 | 每个角色一个主色，**招式之间只靠形状区分**，不靠换色 |
| 尺寸 | 单体招式 ≤ 2.5m；范围招式 ≤ 6m；**不得覆盖玩家脚下 1.2m**（会看不见自己） |
| 时长 | 普攻 0.12–0.18s；技能 0.35–0.6s；处决/暴击 0.25s |
| 数量 | 同屏粒子 ≤ 60；屏震只在暴击/处决/技能触发 |
| 可读性 | 特效最亮部分不能超过 HUD 白色文字亮度；否则 90 只怪时会糊成一片 |

**角色主色**

- 丛雨：绯红 `ff5a6e` + 刀光白 `fff2f0`
- 若叶睦：紫罗兰 `b47bff` + 音符金 `ffd479`
- 大肥鱼：水青 `5fd8ff` + 泡泡白 `eafcff`

## 1. 丛雨

### 1.1 拔刀斩（普攻 · 扇形 130°）
- 参数：0.14s，半径 3.2m，3 段弧线错位，末端收细
- 提示词：
  `bright anime pixel-art slash arc, crimson crescent with white hot core, thin edge taper, 130 degree fan sweep, transparent background, additive glow, clean silhouette, no smoke`

### 1.2 居合突进（技能 · 7.5m 直线）
- 参数：0.45s，起点残影 3 帧 + 路径剑气带（宽 2.4m）+ 终点聚气环
- 提示词：
  `anime pixel dash slash, long crimson blade trail with white core, motion afterimages, converging spirit ring at the end, bright and clean, transparent background, additive`

### 1.3 剑意满 · 燕返强化
- 参数：0.5s，双层弧线 + 十字交叉，比普攻大 1.6 倍
- 提示词：
  `double layered crimson cross slash, anime pixel style, white core, gold sparks at intersection, dramatic but bright, transparent background`

### 1.4 流血（持续伤害）
- 参数：每跳 0.3s，目标脚下小血滴上浮，**不做屏幕血液**
- 提示词：
  `small crimson droplets rising, anime pixel, minimal, 8px, transparent background, additive faint`

### 1.5 E 处决
- 参数：0.25s，目标身上竖向白闪 + 一圈绯红碎环；血条处决线同时亮起
- 提示词：
  `vertical white flash slash, crimson shatter ring, anime pixel, execution impact, bright, transparent background`

### 1.6 F 格挡 / 瞬移
- 参数：0.3s，正面半圆护盾弧 + 瞬移残影 2 帧
- 提示词：
  `semi circular parry shield arc, pale gold rim with white core, anime pixel, clean, transparent background`

## 2. 若叶睦

### 2.2 和弦（穿透音波）
- 参数：0.25s，横向音波条 + 3 个音符符号依次淡出
- 提示词：
  `horizontal sound wave beam, violet with golden music notes embedded, anime pixel, clean edge, transparent background, additive`

### 2.3 Mortis 变身（爆发 + 击退）
- 参数：0.5s，双层同心冲击环（内白外紫）+ 地面音符碎片

  `double concentric shockwave ring, violet outer white inner, anime pixel, music note shards flying outward, bright, transparent background`

## 3. 大肥鱼

### 3.1 泡泡水枪（普攻 · 弹丸）
- 参数：0.2s，水青半透明球 + 白色高光点
- 提示词：

### 3.2 大泡泡爆炸
- 参数：0.35s，气泡破裂（6–8 片弧形碎片飞散）+ 半径 4.2m 水环

## 5. 落地注意

1. **特效不能遮玩家**：所有贴地特效用 2D 平面 + `depthWrite: false`，且半径不超过 6m。
2. **亮度上限**：加色混合叠加 3 层就会过曝，同屏同位置最多 2 层。
3. **别用真实烟雾贴图**：会在像素角色旁边显得脏，改用"方形像素碎片"。
4. **和节拍判定解耦**：节奏分支的 Perfect/Good 提示走 HUD 层，不占用这些特效。
