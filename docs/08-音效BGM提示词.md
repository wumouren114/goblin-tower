# 08 · 音效 / BGM 生成提示词（可直接发给 AI）

> 用途：把下面内容丢给 AI 音频工具（Suno / Udio / ElevenLabs SFX / Stable Audio / 豆包音乐等），产出的文件按 §5 命名放进 `assets/audio_raw/`，我写加载器接入。
> 技术要求：**不要人声、不要采样版权旋律、不要静音头尾**；SFX 单声道 44.1kHz/16bit WAV，BGM 立体声 44.1kHz WAV/OGG，峰值 -3dBFS。

## 1. 整体音色定位（每次生成都带上这段）

```
一款像素风二次元割草 Roguelike（哥布林塔）的游戏音频。
风格：chiptune（8-bit 方波/三角波）为主，叠加现代合成器质感；
色调：明亮、爽快、略带童话感，不黑暗不恐怖；
不要人声、不要歌词、不要版权旋律。
```

## 3. BGM 清单（3 首，循环用）

### 3.1 标题 `bgm_title.ogg`（≈60~90s，可循环）
```
像素风二次元轻音乐，标题界面用。chiptune + 柔和合成器，
中速（90~100 BPM），明亮、安静、有一点期待感，
像在塔下准备出发。无鼓点或极轻鼓点，无人声，结尾可无缝循环。
```

### 3.2 战斗 `bgm_battle.ogg`（≈120~150s，可循环）
```
像素风割草战斗 BGM。chiptune + 现代电子鼓，
快节奏（130~140 BPM），热血、爽快、有推进感，
方波主旋律 + 三角波贝斯 + 轻量鼓组，
中段有小段落起伏（避免一直高潮），无人声，可无缝循环。
```

### 3.3 Boss `bgm_boss.ogg`（≈90~120s，可循环）
```
像素风 Boss 战 BGM。比普通战斗更紧张（145~155 BPM），
低音铜管/失真贝斯 + 快速琶音 + 重鼓，
带一点哥布林野性、滑稽但危险的感觉，无人声，可无缝循环。
```

## 4. 通用追加要求（每次生成都附上）

```
- 不要人声/歌词/口哨
- 不要引用任何已有游戏或歌曲的旋律
- 不要开头/结尾的静音段（BGM 需要可循环）
- 背景噪声干净，不要噼啪爆音
- 输出 44.1kHz；SFX 单声道，BGM 立体声
```
