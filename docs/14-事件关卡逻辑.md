# 14 · 事件关卡逻辑与节奏设计

> 对应数据：`src/data/events.ts`（v2 叙事版）与 `docs/11-事件设计.md`。
> 本文档只定义事件房的关卡体验、节奏流向与跨事件伏笔呼应；**不写概率数字**，身份真伪由运行时随机抽取，线索仅用于辅助判断，不保证唯一正解。

## 一、世界观贯穿口径

- **主角处境**：失忆的勇者带着少女同伴攀塔；塔顶的「恶龙」是最终 Boss 的比喻，击败它才能取回记忆。
- **高塔本质**：塔吞下了别的世界，三大层各自是一段「世界回声」（云上花庭 / 星砂观星台 / 黄铜钟塔），塔真正收集的是「仍想往上爬的人」。
- **记忆碎片与伏笔**：事件中拾得的记忆碎片用来拼回旧世界与过往攀塔的片段；伏笔（`arc`）只在后续真的遇到对应事件时才可能兑现，**允许不了了之**。
- **危与机并存**：同一事件在不同隐藏真身下呈现大赚、平淡或吃亏的强烈反差；吃亏结果一律留出叙事后路，不写成惩罚通知。

---

## 二、四种关卡流向（`flow`）

| `flow` | 交互节奏 | 适用事件 |
| --- | --- | --- |
| `single` | 进入读景 → 一步抉择 → 即时呈现结果与余韵 | `tavern` |
| `two-step` | 进入先看场景与免费线索（观察停顿）→ 展开选项与 `hint` 推断 → 结算与留白 | `peddler`、`trapped-knight`、`lost-child` |
| `chain` | 进入对话 → 做出初次选择 → 触发二次追问或冲突收束（如揭穿假面/交锋）→ 呈现终局 | `chapel`、`duelist` |
| `narrative` | 静默探索与细读氛围 → 轻抉择（凑近/触碰/祭拜/掠过）→ 拾取线索或记忆碎片 | `wall-script`、`nameless-grave` |

## 三、八个事件房的关卡逻辑

### 1. 路边的货郎（`peddler`）
- **flow**：`two-step` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：真商人 `genuine` / 奸商 `swindler` / 落魄勇者 `fallen`
- **进入时看到什么**：回廊转角漏下斜光，裂砖上铺着褪色油布，三件蒙尘旧物旁压着半截旧剑穗，背囊客正朝你和少女招手。
- **能读到的线索**：免费线索 3 条（塔内符文、影子比人慢半拍、包袱里露出一角勇者徽记）；每个选项旁附带 `hint`，引导玩家对照符文走向、影子延迟与对方护包的反应。
- **选择步骤**：先观察摊布与人物神态，再在「买一件（50 金）」「要求验货（20 金）」「用一张卡换」「走开」中择一。
- **结果呈现**：真商人给永久微幅全属性护符、草药或高一档紫卡；奸商则触发反符文标记（两层怪移速提升，但反符文发烫带来警觉）或卷款/骗卡留线索；落魄勇者交出半枚勇者徽记或一段旧名记忆。
- **伏笔与兑现位置**：挂 `fake-peddler-marked`（吃亏留暗线，呼应「塔内伪装与影子失真」）或 `fallen-hero-token`（与 `trapped-knight` 手甲纹章、`duelist` 旧剑客同源，可在后续遭遇中呼应，也可能不了了之）。
- **如何离开**：结算文案与 `epilogue` 播完后确认收起面板，货郎收摊退入阴影，开启本层出口隧道。

### 2. 酒馆的一杯（`tavern`）
- **flow**：`single` ｜ **骨架**：馈赠型（`gift`）｜ **隐藏真身**：老实老板 `honest` / 告密者 `snitch`
- **进入时看到什么**：石壁间嵌着半掩木屋，暖黄灯火混着麦芽与松脂香溢到走廊，屋里有人唱着走调的歌，老板反复擦拭同一个锡杯。
- **能读到的线索**：免费线索 2 条（走调歌声、反复擦同一只杯子）；选项 `hint` 提示低层麦酒多半稳妥，但酒色与眼神皆有变数。
- **选择步骤**：一步抉择——「喝一杯（10 金）」「坐下听他们说话」「请全场喝一杯（60 金）」。
- **结果呈现**：喝酒可能得魔力增益、高增益伴一层视野微醺的「勇者之酒」、酸酒短时降暴击，或在 `snitch` 真身下被顺走 30 金但顺带听见上层口风；坐下听则无风险记下塔顶恶龙与第三声钟的传闻；请客则可能换来移速加成，也可能无人领情。
- **伏笔与兑现位置**：选「坐下听」挂 `tavern-rumor`，与 `wall-script`（第三声钟）及 `chapel`（反念祷词）形成跨事件互证；若后续未遇到对应房间则自然不了了之。
- **如何离开**：播完结算与 `epilogue` 后推门回到冷风回廊，暖光在身后合拢，出口隧道解锁。

### 3. 教堂的牧师（`chapel`）
- **flow**：`chain` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：真牧师 `priest` / 塔的化身 `avatar`
- **进入时看到什么**：积灰彩窗透下灰光，空旷祭坛上没有血迹，只有冷香与远处隐约的黄铜钟余震；灰袍牧师站在光柱中，提出免费治疗但须留下一物。
- **能读到的线索**：免费线索 2 条（祷词里有一个词是反着念的、祭坛上没有血）；若玩家此前读过 `wall-script`，可在「问她为什么」的 `hint` 中产生直觉关联。
- **选择步骤**：先听取条件，在「留下记忆碎片（需持有任意记忆）」「留下金币（40 金）」「问她为什么」「拒绝」中抉择；选「问她为什么」时进入二段收束——或道出塔的真相、或微笑送客、或在 `avatar` 真身下裂面化砖触发单怪遭遇战。
- **结果呈现**：留记忆满血并补全云上花庭世界观；留金稳妥回血；拒绝仍得少量回血；追问则在高风险与关键线索 `tower-collects` 之间博弈。
- **伏笔与兑现位置**：不新挂 `arc`，但作为「第三声钟与反念祷词」的兑现/呼应节点，承接 `wall-script` 与 `tavern-rumor`。
- **如何离开**：若触发 `avatar` 战斗，清完敌人后祭坛归于空寂并开启出口；其余分支在读完 `epilogue` 后推开木门离开。

### 4. 塔壁上的刻字（`wall-script`）
- **flow**：`narrative` ｜ **骨架**：信息型（`info`）｜ **隐藏真身**：无
- **进入时看到什么**：斜光切开石壁明暗，砖缝里落着新鲜石粉，齐肩高处刻着仓促的刀痕：「不要相信第三声钟」。
- **能读到的线索**：免费线索 2 条（字是新的刃口未锈、刻得很深像在赶时间）。
- **选择步骤**：轻叙事抉择——「读下去」细辨被划烂的下半行，或「不看」直接绕过。
- **结果呈现**：细读时多半拼出「祷词反念时，钟已响过两声」的残句并挂上伏笔；少见情况下因驻足太久惊动暗处 3 只伏兵。不看则无事发生。
- **伏笔与兑现位置**：挂 `wall-script`，核心呼应点在 `chapel`（反念祷词）与 `tavern`（第三声钟传闻）；若后续未抽到对应事件则不了了之。
- **如何离开**：未遇伏兵则读完直接沿走廊上行；触发伏兵时清场后石壁归静，解锁出口隧道。

### 5. 知名的勇者（`duelist`）
- **flow**：`chain` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：真勇者 `real` / 假冒者 `fraud`
- **进入时看到什么**：风吹净尘的石阶平台上，披旧斗篷的剑客横剑拦路，空气里有擦剑油味，但他的靴子崭新、剑鞘干干净净。
- **能读到的线索**：免费线索 2 条（自称爬过三次塔却剑未入鞘、靴子是新的）；选项 `hint` 提示从虎口与靴底尘土判断对方求的是对手还是破绽。
- **选择步骤**：初次决定「接受比试」「拒绝」或「站着看他」；选「接受比试」后进入二段收束——真剑客分出胜负（赢则赠紫卡与金币增益，输则短时降耐力但被记住），假冒者则在交锋瞬间滑出暗刃触发单怪战斗并掉落紫卡。
- **结果呈现**：同选接战却在大赚、轻伤留情、识破暗算三端分化；拒绝留下一条冷淡的人情账；静观则无声散场。
- **伏笔与兑现位置**：输掉或拒绝时挂 `duelist-remembers`，与 `peddler`（落魄勇者旧徽记）及 `trapped-knight`（旧攀塔者群像）遥相呼应，后续可能在商路或高层重逢，也可能再无交集。
- **如何离开**：战斗分支清完敌人后收剑离场；其余分支待剑客侧身让路或自行离开后，石阶出口开放。

### 6. 被困的勇者（`trapped-knight`）
- **flow**：`two-step` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：真被困 `honest` / 诱饵 `bait`
- **进入时看到什么**：塌落石梁斜压碎砖堆，尘雾与淡血腥浮在空气里，石缝中伸出一只刻着异界家纹的旧手甲，正一下一下叩击地面。
- **能读到的线索**：免费线索 2 条（石梁下持续敲击、手甲刻着别的家族纹章）；选项 `hint` 提示挖人必然耗血，需听敲击是否像活人呼吸。
- **选择步骤**：先听声辨认手甲纹章，再在「把他挖出来（掉血）」「给他一瓶药」「走开」中择一。
- **结果呈现**：救人短期必然掉 15% 血量——可能换来郑重承诺（挂伏笔），可能对方一言不发离去（塞翁失马的留白），也可能在 `bait` 真身下掀出 3 只伏兵；给药则以低风险留一线善缘；走开后敲击声在身后戛然而止。
- **伏笔与兑现位置**：救人致谢或给药挂 `saved-knight`；手甲家纹与 `peddler` 的落魄勇者徽记同源，后续可能在险境兑现挡刀，也可能他早已独自奔向恶龙、再无瓜葛。
- **如何离开**：诱饵战清场后解锁出口；其余分支在石梁归静、人影远去后继续攀塔。

### 7. 哭泣的孩子（`lost-child`）
- **flow**：`two-step` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：真孩子 `real` / 幻象 `illusion`
- **进入时看到什么**：背阴薄雾里落满枯瓣，小女孩缩在石柱下低声抽泣，说妈妈在塔里；地上有你和少女的影子，她脚边却空无一物。
- **能读到的线索**：免费线索 2 条（没有影子、一直盯着你身后的方向）；选项 `hint` 提醒无影未必全是恶意，但也可能只是无法跨层的回声。
- **选择步骤**：先留意柱影与她的视线，再选「带她走」「给她钱（30 金）」或「不管」。
- **结果呈现**：带她走可能化作永久微幅生命或移速陪伴，也可能换层时消散留下一朵云上花庭干花（记忆碎片）；给钱后她笑着钻进暗廊，表面似被戏弄，笑声却顺带引偏前方暗哨；不管则空地留一枚 5 金旧铜币。
- **伏笔与兑现位置**：带走陪伴或给钱挂 `child-follows`；留下的干花（`child-flower`）与 `nameless-grave` 碑前的新花同种，无影特征亦与 `peddler` 滞后影子呼应「世界回声拼接失真」。
- **如何离开**：确认结局与 `epilogue` 后，薄雾散开，带走或独自迈入下一层隧道。

### 8. 无名的墓碑（`nameless-grave`）
- **flow**：`narrative` ｜ **骨架**：抉择型（`choice`）｜ **隐藏真身**：无
- **进入时看到什么**：寂静石室中央垂落灰蓝微光，半人高素石碑刻着你的名字却没有日期，碑前摆着一束露水未干的新花。
- **能读到的线索**：免费线索 2 条（碑上没有日期、碑前的花是新的）；新花品种暗接 `lost-child` 的干花与云上花庭回声。
- **选择步骤**：静默端详碑文后，在「触碰碑文」「低头祭拜」「离开」中择一。
- **结果呈现**：触碰可能唤回自己倒在雨中与塔顶龙影的记忆碎片（`own-death`），也可能惊醒碑后与你一模一样的残影触发单挑；祭拜平复心神获永久生命微增；离开则无即时变化，但碑文在留白中暗示下一次重逢会刻得更深。
- **伏笔与兑现位置**：不新挂 `arc`，但作为全塔循环与记忆回收的核心回响点，承接 `lost-child` 的花瓣意象，并向 `chapel`（记忆碎片可作为祭坛筹码）反向供料。
- **如何离开**：残影战胜利或静默收尾后，石门无声开启，通往下一层。

## 四、三组跨事件呼应总览

1. **「第三声钟」与反念祷词**（`wall-script` ⇄ `tavern` ⇄ `chapel`）
   - 塔壁刻字警告「不要相信第三声钟」并残留「祷词反念时，钟已响过两声」；酒馆传闻提到高处黄铜钟塔第三声钟会收走名字；教堂牧师的祷词恰好反念一词且伴随钟声余震。玩家可借前两处的片段提高对牧师的警觉，但因真身仍随机，无法百分百断定。
2. **旧世界攀塔者的徽记与手甲**（`trapped-knight` ⇄ `peddler` ⇄ `duelist`）
   - 被困骑士手甲上的旧国纹章、落魄货郎包袱里的半枚勇者徽记、知名剑客关于三次登塔的旧事，共同拼出「曾有无数人带着执念攀塔并折在半途」的群像。救人或交易换来的 `saved-knight` / `fallen-hero-token` / `duelist-remembers` 均可能后续呼应，也可能各奔前程、不了了之。
3. **回声失真与云上之花**（`lost-child` ⇄ `nameless-grave` ⇄ `peddler`）
   - 哭泣女孩没有影子、奸商影子慢半拍，都是世界回声拼接不严的征兆；女孩消散留下的干花，与无名墓碑前露水未干的新花同出云上花庭，暗示主角与这段世界回声早已不止一次重逢。
