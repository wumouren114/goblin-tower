# 《哥布林之塔》设计框架 v0.1

> 本文是这一版可玩 Demo 的「设计底稿」：先拆解同类游戏的玩法与战斗设置，再给出本作的框架、数值与技术实现。
> 本轮按你的要求**先复现底层设定 + 第三人称场景**；角色形象、前端细节、战斗系统与经济系统等你后续给需求，再统一替换调参。
> 所有数值集中在 `src/data/gameConfig.ts` 与 `src/data/floors.ts`，改数值不用翻逻辑代码。

---

## 1. 一句话定位

**二次元像素风的 3D 俯视角割草 Roguelike 爬塔**：在五层塔里不断击杀四面涌来的哥布林，靠经验豆与金币升级、三选一强化，一路变强打到最深层，击败哥布林之王、抢走它身上的传送卷轴逃出这个世界。

- 爽感来源：**成片倒下的杂兵 + 肉眼可见的变强 + 满屏飘字/粒子/屏震**
- 挑战来源：**层数越深怪越硬越痛、刷新越密；噩梦难度与 Boss 二阶段**

## 2. 同类游戏拆解（我们抄什么、不抄什么）

| 参考 | 类型 | 可借鉴 | 不照搬 |
| --- | --- | --- | --- |
| 《吸血鬼幸存者》 | 幸存者类（Bullet Heaven） | 自动攻击、经验升级三选一、怪潮密度、武器进化 | 单场景无限刷，没有爬塔目标感 |
| 《土豆兄弟》 | 幸存者类 + 波次 | 短局节奏、每波结算、明确的 Build 方向 | 纯数值商店，缺少动作操作 |
| 《Halls of Torment》 | 幸存者类 3D 化 | 3D 俯视角、预渲染氛围、拾取吸附手感 | 美术成本高，不是像素二次元 |
| 《黑帝斯》 | 动作 Roguelike | 房间推进、Boss 演出、死亡叙事、祝福三选一 | 手工关卡量大，不适合小团队首版 |
| 《死亡细胞》 | 动作 Roguelike | 手感打磨（前摇/停顿/屏震）、武器差异化 | 平台跳跃与精确操作，割草不需要 |
| 《杀戮尖塔》 | 爬塔卡牌 | 分层地图、Boss 前的资源规划 | 回合制，不是实时割草 |

**结论**：本作 = 幸存者类的「成长与怪潮」+ 爬塔的「分层目标」+ 动作游戏的「打击手感」。核心是**低操作门槛的爽**，深度放在 Build 与难度选择上。

### 2.1 三层循环

```
秒级：走位聚怪 → 回旋刃自动切割 → 掉落弹跳 → 吸附入袋 → 飘字/音效反馈
分钟级：攒经验升级 → 三选一 → 面板肉眼变强 → 击杀数达标 → 楼梯开启 → 下一层（怪更强）
单局级：通关卷轴 / 死亡 → 结算 → 换难度或重开
```

## 3. 玩法框架

### 3.1 一局流程

1. **标题页**：选难度（休闲 / 标准 / 噩梦），看操作说明。
2. **第 1–4 层**：每层是方形石厅（17–23m 半边长），哥布林从四面墙边的刷新点涌出。
   - 目标：**击杀达到配额**（25/40/55/70）或拖到**兜底计时**（150–195s），北侧楼梯门开启。
   - 走到楼梯旁按 `E` 进入下一层；换层刷新主题（苔石 / 烛影 / 熔火 / 霜蚀 / 王座）。
3. **第 5 层 王座之巅**：哥布林之王登场（2600 HP，砸地 + 召唤 + 二阶段冲锋），击杀后掉落**传送卷轴**。
4. **拾取卷轴 → 通关结算**；血量归零 → 死亡结算。两者都可原难度重开。

### 3.2 移动与操作（键鼠）

| 输入 | 行为 |
| --- | --- |
| `WASD / 方向键` | 屏幕系移动，角色按镜头方向转换世界系 |
| `Shift / 空格` | 冲刺（0.16s 无敌，CD 1.4s，升级可减） |
| `E` | 在楼梯旁交互，进入下一层 |
| 鼠标拖拽 / 滚轮 | 镜头环绕 / 缩放 |
| `V` | 切换「割草视角（高机位）/ 探索视角（低机位）」 |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

**镜头**：第三人称跟随，默认 13.5m 距离、11.5m 高度的俯视角，看得清全场（幸存者类的舒适区）；`V` 切到 9.2m / 4.6m 的低机位，用来看清角色的像素细节与塔内纵深。

### 3.3 战斗设置（本版占位实现）

- **自动武器：回旋刃**。围绕角色匀速旋转的 2 把能量刃，碰到敌人就结算伤害；每把刃对同一目标有 0.42s 命中冷却，防止每帧无限连击。升级可加刃数、轨道半径、转速、伤害、暴击。
- **伤害公式**：`伤害 = 攻击力 × (暴击 ? 暴击倍率 : 1)`，再被敌人护甲/减伤修正（当前敌人无减伤）。
- **受击**：接触伤害按敌人 `damage`，玩家有 0.65s 无敌帧；受击触发闪白 + 0.18s 红晕 + 屏震 + 击退。
- **敌人 AI**：直线追踪 + 障碍推挤 + 互相分离（防止叠成一个点）+ 场地边界约束。
- **Boss AI**：追击 → 0.85s 地面红圈预警 → 砸地 AOE → 硬直；血量 <55% 进入二阶段，追加直线冲锋与召唤 5 只哥布林。
- **打击手感清单**（已接线的部分）：
  - 命中：粒子火花 + 短促音效 + 敌人闪白击退 + 飘字（暴击更大更黄）
  - 击杀：爆散粒子 + 经验豆/金币弹出 + 死亡缩小旋转淡出
  - 受击：红晕 + 屏震 + 低沉音效 + 无敌闪烁
  - 升级：金色双光环 + 五音上行 + 全屏吸经验
  - Boss：登场吼叫 + 红圈预警 + 砸地屏震 + 血条

### 3.4 怪潮节奏

按「适应期 → 加压 → 精英 → Boss」四段设计：

| 阶段 | 时间 | 内容 |
| --- | --- | --- |
| 适应期 | 0–20s | 小批哥布林，熟悉操作与拾取 |
| 加压期 | 20–90s | 刷新间隔随层内时间缩短（每 4s ×0.985），混入蛮兵 |
| 精英期 | 每 22s | 一只哥布林勇士（4.2× HP、5× 经验、必掉金币）刷新新鲜感 |
| 收尾 | 达标/超时 | 楼梯开启，主动引导玩家进入下一层 |

第 5 层改为 Boss 战 + 持续小怪骚扰，Boss 每 9s 召唤一次援军。

## 4. 经济系统（本版占位实现）

### 4.1 资源

| 资源 | 来源 | 用途 |
| --- | --- | --- |
| 经验（青色豆） | 击杀掉落、地上散落、升级时全吸 | 升级 → 三选一 |
| 金币 | 击杀概率掉落、地上金币堆、精英/Boss 掉落 | 当前仅计分；后续接商店/重铸 |
| 生命（红心） | 精英 40% 掉落 | 回 25 HP |

**拾取手感**：进入 `pickupRadius × 2.4` 后先向外弹一下，再加速飞向玩家（幸存者类标配的「吸」的爽感）；升级瞬间 `vacuumAll()` 把全场豆子吸过来。

### 4.2 升级曲线

- 升级所需经验：`round(9 × 1.27^(lv-1) + 2 × (lv-1))`，第 1 级 9 点，10 级约 92 点。
- 每次升级 **三选一**，13 种升级项覆盖伤害/攻速/范围/刃数/移速/生命/拾取/经验/金币/暴击/减伤/冲刺。
- 加权随机（史诗权重低），满层后移出卡池；连续升多级会连续弹卡。

### 4.3 难度与掉落

| 难度 | 怪物 HP | 伤害 | 刷新 | 经验 | 金币 |
| --- | --- | --- | --- | --- | --- |
| 休闲 | ×0.78 | ×0.7 | ×0.85 | ×1.2 | ×1.15 |
| 标准 | ×1 | ×1 | ×1 | ×1 | ×1 |
| 噩梦 | ×1.5 | ×1.4 | ×1.3 | ×0.92 | ×1.25 |

层数成长：`hpScale` 1 → 1.7 → 2.7 → 4.1 → 5.2，`damageScale` 1 → 1.35 → 1.7 → 2.1 → 2.3。**玩家变强靠升级，怪物变强靠层数**，两条曲线交叉点就是难度手感。

### 4.4 数值表（节选）

| 项 | 值 |
| --- | --- |
| 玩家基础 HP / 移速 / 攻击 | 120 / 6.4 / 14 |
| 回旋刃轨道半径 / 数量 / 角速度 | 2.7m / 2 / 1.55 rad·s⁻¹ |
| 暴击 | 8% × 1.8 |
| 冲刺 | 19 m/s × 0.16s，CD 1.4s |
| 小/大/精英哥布林 HP | 30 / 85 / 126 |

## 5. 技术框架

### 5.1 技术栈

`Vite 5 + TypeScript(strict) + three.js (WebGL)`。零外部美术素材：**所有像素图与地砖都由 Canvas2D 程序化生成**，音效由 WebAudio 实时合成，离线可跑、无版权风险。

### 5.2 模块划分

```
src/
  main.ts              启动：创建 HUD、Game、渲染循环
  game.ts              总控：相位机（标题/战斗/升级/死亡/通关）、波次、楼层流转、Boss 流程
  types.ts             全模块共享类型（PlayerStats / FloorDef / HudSnapshot ...）
  core/                输入、音频、事件总线、随机数、数学工具
  data/                数值与配置（gameConfig / floors / upgrades）
  art/                 程序化像素图集（主角/哥布林/王/粒子）
  entities/            Player / Goblin / GoblinKing / PickupManager
  world/               TowerFloor：地面、墙体、祭坛、障碍、火把、楼梯门、灯光雾效
  systems/             相机、回旋刃、粒子特效、属性计算、全屏表现
  ui/                  HUD、标题页、升级三选一、Boss 血条、飘字、结算
```

### 5.3 关键设计

- **实体自管渲染**：每个实体持有 `THREE.Group`，`game.ts` 只负责 `scene.add` 与调用 `update(dt, ...)`，方便后续把哥布林换成任意模型。
- **面板与表现分离**：战斗只读 `PlayerStats`，升级只改 `PlayerStats`，表现层不参与数值。
- **程序化世界**：`TowerFloor.build(def, theme, difficulty)` 每次进层重建；主题色板驱动地面/墙体/雾/灯光，一个新层 = 一份配置。
- **对象池**：粒子 320 + 光环 28 全部复用，哥布林死亡动画结束才真正释放，避免 GC 卡顿。
- **程序化音效**：13 种音效全部由振荡器/噪声合成，按事件触发，无音频文件。

## 6. 后续扩展路线（按优先级）

1. **战斗系统**：武器树（飞刃/链锤/符咒/召唤物）、超武进化、主动技能与词条；怪物种类与攻击前摇。
2. **经济系统**：金币商店（临时增益/重铸/复活）、遗物、层间事件房、难度奖励。
3. **前端包装**：主菜单、角色选择、图鉴、结算动画、成就、存档。
4. **内容量**：更多楼层主题与词缀（每层随机 1 个环境词缀）、Boss 2–3 种、无尽模式。
5. **移动端**：虚拟摇杆、自动瞄准开关、性能档位。

## 7. 调参入口

- 基础数值：`src/data/gameConfig.ts` 的 `CONFIG`、`DIFFICULTY`、`GOBLIN_*`、`THEMES`
- 楼层与目标：`src/data/floors.ts` 的 `FLOORS`
- 升级卡池：`src/data/upgrades.ts` 的 `UPGRADES`
- 手感参数：`CONFIG.camera`、`CONFIG.blade`、`CONFIG.combat`、`CONFIG.boss`
