# 事件设计 · v1（探索类隧道）

> 事件是第二重要的玩法。它不是"选择题"，而是**一段可能什么都不发生、也可能改变后面几层运气的小遭遇**。

## 0. 五条原则

1. **不写死身份**。同一个事件在不同局里是不同的人：货郎可能是真商人、也可能是骗子、也可能是个落魄的勇者。玩家只能靠线索把胜率往上抬，抬不到 100%。
2. **不给概率数字**。设计文档里不写"35% / 40%"，只写"常见 / 少见 / 未必"。概率交给运行时按权重抽，调手感时再改。
3. **惩罚轻，奖励也难**。单次最多掉一层左右的收益 + 一段短时减益；**不扣生命上限、不删卡、不结束本局**。高价值奖励只在"看懂了线索并押对"时出现，而且不会比这更频繁。
4. **允许"不了了之"**。伏笔不一定兑现：后续事件没刷出来、或者刷出来了但没抽中，这段就此结束。**这不是 bug，是设计。**
5. **危与机并存，且可以错位**。短期吃亏、长期变好（救了个勇者，他后来替你挡刀）；短期占便宜、长期变坏（捡了不该捡的东西）。也有纯收益事件和纯信息事件——不是每个事件都要有代价。

## 1. 事件的三种骨架

| 骨架 | 结构 | 例子 |
| --- | --- | --- |
| **抉择型** | 情景 + 2–4 选项，结果按隐藏身份分派 | 货郎、比试、哭泣的孩子 |
| **信息型** | 只有"看/不看"，收益是知识或伏笔，**没有惩罚** | 塔壁刻字、墓碑 |
| **馈赠型** | 只有收益或无收益，没有惩罚 | 酒馆（前段才有）、路边摊的剩饭 |

**出现区间**：每个事件绑定"可出现的层段"。酒馆只在前段（5 层之前），深处没有——同一局里你错过就真的错过了。

## 2. 伏笔（arc）

一个事件可以挂一条 `arc`（伏笔），后面的事件**按层段随机**去兑现它：

```
救下勇者 → arc: 'saved-knight'
   → 后续（任意层）遇到「负伤的骑士」事件时：
        · 若 arc 命中：他替你挡一次致命伤害
        · 若未命中：该事件变成普通遭遇，与你无关
   → 若本局结束前都没兑现：不了了之
```

**兑现与否由"后续事件是否出现"决定，不额外掷骰**——这样玩家永远不知道自己是"运气不好"还是"故事就该这样"。

## 3. 八个事件

### 3.1 路边的货郎（抉择型 · 前段/中段）
摊布上三件货，报价只有市价一半。

**线索**：货上有塔内符文；影子比人慢半拍；包袱里露出一角勇者徽记。

| 选项 | 结果（按真身） |
| --- | --- |
| 买（花钱） | 真商人 → 真护符（全属性小幅永久提升）／奸商 → 假货，**被标记**：接下来两层敌人更快／落魄勇者 → 遗物徽记（伏笔） |
| 验货（花小钱） | 真商人 → 大方给你看，多送一瓶药／奸商 → 转身就跑，钱白花／落魄勇者 → 沉默很久，把徽记白送 |
| 用一张卡换 | 真商人 → 换到同档更好的卡／奸商 → 卡没了／落魄勇者 → 徽记 + 一段世界观（记忆碎片） |
| 走开 | 无。中段以后可能再遇见他的尸体（可搜刮，也可能被埋伏） |

**惩罚强度**：只有"被标记"和"白花小钱"两种，都只影响 1–2 层。

---

### 3.2 酒馆的一杯（馈赠型 · **仅前段**）
木屋里有人在唱走调的歌，老板擦着杯子问你喝不喝。

| 选项 | 结果 |
| --- | --- |
| 喝 | 多半是普通的酒（小幅增益两层）；偶尔是"勇者之酒"（大幅增益，但醉意：视野变窄一层）；偶尔是劣酒（命中下降，两层后自动消） |
| 不喝，坐下听 | 听到一段消息（伏笔：下一层的某类事件会多一个选项） |
| 请全场喝一杯 | 花钱，换来"这一层敌人移速降低"（人气加成），或者什么也没换到 |

**为什么只在前段**：深处没有活人开的酒馆。错过就没了。

---

### 3.3 教堂的牧师（抉择型 · 中段）
她说治疗免费，但要你"留下一样东西"。

| 选项 | 结果 |
| --- | --- |
| 留下记忆碎片 | 全额治疗 + 一句关于塔的真相（世界观推进） |
| 留下金币 | 全额治疗，无其他 |
| 拒绝 | 只回一点血；她不会拦你 |
| 反问"为什么" | 可能得到真相，也可能被请出去（无损失） |

**惩罚强度**：没有真正的惩罚，只有"少拿"。

---

### 3.4 塔壁上的刻字（信息型 · 任意层）
墙上有前人用刀刃刻的字。

| 选项 | 结果 |
| --- | --- |
| 读 | 获得知识与伏笔（某些事件会因此多一个选项）；**偶发**：读得太久，被怪围上来 |
| 不读 | 什么都没有 |

**惩罚强度**：偶发一次小遭遇，不掉资源。

---

### 3.5 知名勇者的比试（抉择型 · 中段）
他自称爬过三次塔，剑没入鞘。

| 选项 | 结果 |
| --- | --- |
| 接受比试 | 赢 → 名声（后续商人给折扣）+ 一张卡；输 → 轻伤（短时减益）+ 他请你喝一杯（伏笔） |
| 拒绝 | 他记住了你：后面可能替你说话，也可能在塔顶与你为敌 |
| 旁观 | 无 |

---

### 3.6 救一个被困的勇者（抉择型 · 任意层）
他被压在塌下来的石梁下。

| 选项 | 结果 |
| --- | --- |
| 救（耗时 + 掉一点血） | 他道谢离开（伏笔）：后面可能来替你挡一次致命伤；**也可能再无瓜葛** |
| 不救 | 他可能记恨（后面变成敌人）；也可能什么都没发生 |
| 给他一瓶药就走 | 小幅善意（伏笔偏正面，但更弱） |

**这是"塞翁失马"的核心事件**：救人是短期负收益，长期可能一文不值，也可能救你一命。

---

### 3.7 哭泣的孩子（抉择型 · 中后段）
她说妈妈在塔里。

| 选项 | 结果 |
| --- | --- |
| 带她走 | 她跟着你（长期占一个"随从位"，给很小的增益）；**也可能**她是塔的幻象，某一层突然消失并留下东西 |
| 给她钱 | 她跑开；可能再遇见（伏笔），也可能被骗 |
| 不管 | 她消失，地上留下一样小东西（可能有用，可能只是垃圾） |

---

### 3.8 无名的墓碑（抉择型 · 后段）
碑上刻着你自己的名字。

| 选项 | 结果 |
| --- | --- |
| 触碰 | 得到一块记忆碎片；**偶发**：触发一场与"过去的自己"的战斗 |
| 祭拜 | 小幅永久增益（心境） |
| 离开 | 无。但下一次再遇到类似事件时，碑文会变 |

---

## 4. 数值口径（统一约束）

| 项 | 上限 |
| --- | --- |
| 金币 | 单次得失 ≤ 一层的清层收益 |
| 卡 | 最多 1 张，且不会直接给金卡（金卡只能靠"押对高风险选项"） |
| 减益 | ≤ 3 层，且必定自动消失 |
| 永久增益 | 全属性 ≤ 12%，且只在小概率分支出现 |
| 战斗 | 最多一场小规模遭遇，不安排 Boss |
