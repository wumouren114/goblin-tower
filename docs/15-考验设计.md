# 15 · 「考验」门设计

> 对应数据：`src/data/trials.ts`（纯数据 + 类型，不依赖运行时模块）。
> 「考验」是高塔称量攀塔者的另一种方式：它不靠隐藏真身，而是把条件摆在明面上——**先背负一段看得见的约束或一场直面交锋，熬过之后换取长线转正收益**。拒绝考验一律不惩罚，留给玩家按当前局势自由取舍。

## 二、六条考验详细设计

### 1. 税吏之誓（`tax-oath` · 经济流）
- **立约**：旧账税吏·维尔是旧城邦坠入高塔前留下的记账人，在回廊里靠拨算珠维持旧日秩序。他提出先抽走接下来三层一半的沿途金币，期满再按玩家届时账面余额发还一笔红利。
- **期间**：连续 3 层金币获取 `-50%`。玩家必须在「立刻买卡补战力」与「攥紧现金冲高到期基数」之间做经济权衡。
- **兑现**：通关第 3 层时结算，立刻获得当前持有金币的 `40%`（余额越高，滚雪球回报越大）。
- **文案要点**：慢条斯理、句尾带「你考虑清楚」；台词只说「分一半收成、期满按底子连本带利还你」，不直接念百分比；拒绝时合上账本，不嘲讽。

### 2. 破釜之誓（`burn-boats` · 风险流）
- **立约**：断甲斥候·加伦是在星砂观星台折断盾牌的旧攀塔者残影。他要求玩家卸下硬扛的习惯，在更高承伤压力下练出走位。
- **期间**：连续 3 层受到伤害 `+25%`。在无冲刺的战斗节奏下，容错显著收紧，迫使玩家更精准地拉扯远程怪与冲锋线。
- **兑现**：撑过 3 层后，永久获得 `闪避 +12%`，在高密度后期层数中大幅提升生存上限。
- **文案要点**：短促干脆，强调「别用血肉去换，盯着起手」；拒绝时肯定「先活着才能往上爬」，留足分寸。

### 3. 切磋（`duel-pact` · 技巧流）
- **立约**：守阶剑师·洛安是走不到塔顶、又不愿化作无声回声的旧日剑客，守在阶前向路过的勇者发出单挑邀约。
- **期间**：当场与 NPC 单挑 1 场（即时检验操作与当前构筑强度，不跨层拖累）。落败不会导致本局结束，但会以 `生命上限 -12%` 作为挫伤代价。
- **兑现**：单挑获胜立刻奖励 `专武 +1 级`（在当前 `TrialDef` 通用字段中以 `goal.kind = 'eliteKills'`、`boon.stat = 'attack', value = 1` 占位，具体单挑结算由系统层接线读取 `id === 'duel-pact'` 处理）。
- **文案要点**：低沉克制、惜字如金；说明「赢则替你再淬兵刃、输则留手但元气受损」；拒绝时各自收势，保持武人礼数。

### 4. 禁食之誓（`fasting-oath` · 续航流）
- **立约**：枯井修女·赛拉来自云上花庭的旧修道院。她认为塔里的药香只是世界回声的借物，提议玩家立下三层节制之誓，靠自身骨血挺过战损。
- **期间**：连续 3 层治疗效果 `-60%`（红心、回血技能与恢复手段全部大幅打折），考验玩家控血与规避消耗战的能力。
- **兑现**：戒期满后永久获得 `生命上限 +15%` 与 `每秒回复 0.5% 生命`，将前期节制转化为持久战的稳定底盘。
- **文案要点**：轻稳带冷雾感，呼应「云上花庭干涸的旧泉」与失忆勇者的来路；拒绝时祝对方带好药瓶，温和克制。

### 5. 负重行军（`forced-march` · 机动流）
- **立约**：逃兵军需官·马科是从旧世界防线逃入高塔的辎重兵，总背着两袋冷铁。他让脚步轻快的勇者替自己扛两层铁袋，换取卸甲后的轻盈身法。
- **期间**：连续 2 层 `移速 -15%` 且 `每层敌人数量 +20%`。移速下降叠加怪潮加密，是六条里短期压迫感最强、但持续层数最短的考验。
- **兑现**：扛过 2 层卸下铁袋后，永久获得 `攻速 +10%` 与 `移速 +8%`，极适合靠拉扯和频率打输出的机动流派。
- **文案要点**：粗声实在，把「移速变慢、铁锈味招来更多东西」自然写进军需官的口吻里；拒绝时不讥讽，自嘲自己慢慢挪。

### 6. 沉默之誓（`silence-oath` · 技能流）
- **立约**：封钟学徒·伊莎是黄铜钟塔中被拔去钟舌的学徒残影。她邀请玩家暂时封缄蓄力之泉，学会在没有频繁大招的情况下周旋。
- **期间**：连续 3 层 `充能获取 -40%`，逼迫依赖右键技能爆发的构筑暂时回归普攻与走位基本功。
- **兑现**：3 层解封后永久获得 `技能伤害 +20%` 与 `充能上限 +12`，显著放大后期技能爆发循环。
- **文案要点**：嗓音偏哑、停顿偏长，呼应黄铜钟塔与「钟声之外的回响」；拒绝时认可留着底牌护身更稳妥。
