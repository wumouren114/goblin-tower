# 07 · 原画 / 像素资源需求（给美术/AI 出图用）

> 当前版本所有图形都是代码程序化生成的低分辨率像素（角色 48×56）。目标：换成**更高分辨率的像素图集**，保持像素风、可无损放大（Nearest）。
> 出图后把 PNG 按下面的文件名放进 `assets/art_raw/`，我会写导入器替换程序化图集（找不到文件时自动回退到现在的代码图，不会崩）。

## 0. 通用规则（所有图都要满足）

- 格式：**PNG，透明背景**，无抗锯齿（边缘硬边），不要外发光/模糊/半透明羽化。
- 光照方向：**左上打光**（左肩/头顶亮，右侧和下方暗）。
- 描边：角色/怪物统一 **1px 深色描边 `#1a1420`**；道具/特效可无描边。
- 调色：单张图 **≤ 32 色**，颜色取自对应角色色板（见 §2），不要出现渐变色带。
- **不要**：背景、阴影、光晕、文字、水印、网格线、单元格之间的留白或边框。
- 图集网格必须**严格等分**：每一格内容居中、**脚底贴格子底边**（脚下留 0~2px 透明）。
- 动画朝向：行 = 下/上/左/右（4 行）；左向由右向镜像也可以，但请直接给 4 行完整版。
- 命名与格数严格按下面规格，超格/缺格会导致导入失败。
