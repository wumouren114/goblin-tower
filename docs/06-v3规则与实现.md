## 2. 一局流程

```
标题（难度三卡 + 角色三卡 + 继续游戏）
└─ 第 1 层 … 第 N 层（每层：60s 内清完固定数量哥布林）
   ├─ 清空 → 时空隧道三选一（奖励 / 交易 / 对战）
   │   ├─ 奖励房：宝箱金币 或 随机技能卡
   │   ├─ 交易房：商店（4 格）或 祭坛（献金换卡）
   │   └─ 对战房：怪潮 / 精英战（清空后进商店）
   ├─ 商店（4 格 + 25 金重掷 + 背包）→ 下一层
   └─ 阶段末层：Boss 层（90s，击杀哥布林之王）
        └─ 最后一层 Boss → 通关结算
```

- 难度结构：简单 7 层（1 阶段）、普通 5+7 层（2 阶段）、困难 5+5+5 层（3 阶段）。
- 每阶段 3 张场景轮换，阶段末层固定 Boss 场景（王座之巅等）。
- 死亡原因只有两种：血量归零（`hp`）、倒计时归零（`timeout`）。

## 3. 战斗（左键 / 右键）

- 左键按住 = 持续普攻，按攻速节流；右键 = 技能，消耗充能（击杀获得，层间起手 50%）。
- 伤害 = `武器基础伤害 × 魔力 / 100`，暴击 8% ×1.8；射程 = `基础范围 × 智力 / 100`。
- 三角色：
  - **若叶睦**（中距弹道）：扔小黄瓜单体；右键变身 Mortis 8s，耐力/魔力↑、智力↓、减伤 15%，周围音波脉冲。
  - **丛雨**（近战 AoE）：拔刀扇形 110°，一次最多 8 个目标；右键远距突进 + 聚怪 + 回血。
  - **蓝色大肥鱼**（远程）：高攻速泡泡；右键召唤小肥鱼（lv5 五只）协同攻击 10s。
- 专武 5 级，全部改动写在 `src/data/balance.json` 的 `weapons` 段。

## 4. 经济

- 金币来源：单杀（1~11/只，每 4 层 +1）、清层（60+14×层）、Boss（60~）、隧道宝箱（80+14×层）、战斗房（×1.2 / ×1.8）。
- 金币出口：专武券（90/180/320/520）、增益卡（45~60 基准，随层涨价 ×(1+0.14×(层-1))）、药水 20 / 充能电池 15、商店重掷 25、祭坛献金 30+15×层。
- 品质档：第 4 层起可能出现「精制」（×1.9 数值 / ×2.4 价格），第 9 层起「臻品」（×3.2 / ×5.5）。
- 背包 12 格；两张**同级同种**卡合成下一级，数值 ×2，最高 3 级。

## 5. 数值验证

`sim/simulate.mjs` 为整局蒙特卡洛（500 局）：简单 100%，普通 99.0~100%，困难 64.6%~80.4%（三角色），困难平均清层 22~25s / 限时 60s。
复跑：`node sim/simulate.mjs --runs 500 --difficulty hard --verbose`。

## 6. 操作

| 输入 | 行为 |
| --- | --- |
| WASD / 方向键 | 移动（屏幕系，自动按相机朝向转世界） |
| 鼠标左键（按住） | 普攻，朝鼠标指向 |
| 鼠标右键 | 技能（充能满时可用） |
| Shift / Space | 冲刺（短无敌） |
| 鼠标中键拖拽 / 滚轮 | 转视角 / 缩放 |
| V / P / M / I | 切视角 / 暂停 / 静音 / 背包（商店中） |
