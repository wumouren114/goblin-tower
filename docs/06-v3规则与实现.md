## 2. 一局流程

```
标题（难度三卡 + 角色三卡 + 继续游戏）
└─ 第 1 层 … 第 N 层（每层：清完固定数量哥布林，无倒计时）
   ├─ 清空 → 清层奖励三选一（增益卡）→ 时空隧道三选一（奖励 / 交易 / 对战）
   │   ├─ 奖励房：宝箱金币 或 随机技能卡
   │   ├─ 交易房：商店（4 格）或 祭坛（献金换卡）
   │   └─ 对战房：怪潮 / 精英战（清空后进商店）
   ├─ 商店（4 格 + 金币训练 + 25 金重掷 + 背包）→ 下一层
   └─ 阶段末层：Boss 层（击杀哥布林之王）
        └─ 最后一层 Boss → 通关结算
```

- 层末固定两步：先领「清层奖励 · 三选一」增益卡，再进「时空隧道 · 选择路线」；两屏分别用暖金/冷青氛围、礼物/罗盘图标和 STEP 1/2、2/2 标识区分。
- 难度结构：简单 7 层（1 阶段）、普通 5+7 层（2 阶段）、困难 5+5+5 层（3 阶段）。
- 每阶段 3 张场景轮换，阶段末层固定 Boss 场景（王座之巅等）。
- Boss 层以「击杀哥布林之王」为唯一通关条件；小怪只作干扰，不参与清层计数，HUD 不显示小怪配额。Boss 死亡同时计入全局累计击杀。
- 死亡原因只有一种：血量归零（`hp`）。没有倒计时/超时失败。

## 3. 战斗（左键 / 右键）

- 左键单击 = 单次普攻，按攻速节流；按住不会连发。点击后自动锁定射程内最近敌人。右键 = 技能，消耗充能（击杀获得，层间起手 50%）。
- 伤害 = `武器基础伤害 × 魔力 / 100`，暴击 8% ×1.8；射程 = `基础范围 × 智力 / 100`。
- 三角色：
  - **若叶睦**（中距弹道）：扔小黄瓜单体；右键 变身 Mortis 8s，耐力/魔力↑、智力↓、减伤 15%，周围音波脉冲。
  - **丛雨**（近战 AoE）：拔刀扇形 110°，一次最多 8 个目标；右键 远距突进 + 聚怪 + 回血。
  - **蓝色大肥鱼**（远程）：高攻速泡泡；右键 召唤小肥鱼（lv5 五只）协同攻击 10s。
- 专武 7 级，全部改动写在 `src/data/balance.json` 的 `weapons` 段。

## 4. 经济

- 金币来源：单杀（1~11/只，每 4 层 +1）、清层（60+14×层）、Boss（60~）、隧道宝箱（80+14×层）、战斗房（×1.2 / ×1.8）。
- 金币出口：专武升级（110/190/300/450/900/1700）、增益卡（45~60 基准，随层涨价 ×(1+0.14×(层-1))）、药水 20 / 充能电池 15、商店重掷 25、祭坛献金 30+15×层、**金币训练**（基础 60，随层与购买次数上涨）。
- 品质档：第 4 层起可能出现「精制」（×1.9 数值 / ×2.4 价格），第 9 层起「臻品」（×3.2 / ×5.5）。
- 背包 18 格；两张**同级同种增益卡**合成下一级，数值 ×2，最高 3 级。金币训练不占格。

### 8.1 前期发育保护（warmup）

除困难模式外，前 3 层给玩家充足发育时间：小怪更脆、伤害更低、刷新更慢、同屏更少。

| 层 | 小怪血量 | 小怪伤害 | 刷新间隔 | 同屏上限 |
| --- | --- | --- | --- | --- |
| 1 | ×0.70 | ×0.50 | ×1.20 | ×0.60 |
| 2 | ×0.80 | ×0.65 | ×1.12 | ×0.72 |
| 3 | ×0.90 | ×0.80 | ×1.05 | ×0.85 |
| 4+ | ×1.00 | ×1.00 | ×1.00 | ×1.00 |

困难模式只保留第 1 层（×0.88 血 / ×0.72 伤 / ×1.1 间隔 / ×0.85 同屏），第 2 层起全量压力。
数值定义在 `balance.json` 的 `warmup` 段，访问器 `warmupFor()`。

## 9. v3.2 调整（第二轮试玩反馈）

反馈：若叶睦充能太快/大招太强、三选一没有确认键会误触、若叶睦射程太远伤害太高、专武太便宜、普通第 2 层太容易、要加会打弹幕的远程怪、要能暂停、Edge 右键容易触发「返回上一页」导致丢档。

| 问题 | 处理 |
| --- | --- |
| 若叶睦充能太快 | 新增角色充能系数 `chargeGainMul`：若叶睦 **0.55**、丛雨 1.0、肥鱼 1.25；击杀充能 = 基础值 × 系数 |
| 若叶睦射程/伤害过高 | 射程 8→5.5m、基础伤害 16→14、弹速 22→18；自动索敌半径改为「武器射程 +2m」，不再全屏锁敌 |
| 三选一误触 | 卡牌点击只**选中**（高亮），必须点「确认选择」或按 Enter/E 才生效；数字键 1/2/3 也改为选中 |
| 专武太便宜 | 专武升级 90/180/320/520 → **140/260/430/650**；同层买卡 vs 攒钱升级需要权衡 |
| 普通前期太容易 | 新增难度怪物数量系数 `countMul`：简单 0.9、普通 **1.2**、困难 1.2（同屏与总数同步提高） |
| 缺远程怪 | 新增 **哥布林咒术师**（caster）：保持 6~10m 距离、每 2.6s 丢紫色弹幕（伤害 = 该层远程怪伤害 ×0.9），第 2 层起出现，概率 10%（每层 +2%，上限 24%）；美术由 art-v3 新增 caster 图集 + 敌方弹幕图集 |
| 需要暂停 | 底部 `P 暂停` 改成可点击按钮；暂停面板本身保留继续/存档/读档/静音/返回标题 |
| Edge 右键返回上一页 | 技能新增 **Q** 键（右键仍可用）；拦截鼠标侧键 3/4 与 auxclick，避免前进/后退；游戏进行中离开页面触发浏览器 beforeunload 提示，防止误触丢档 |

模拟（v3.2 当时，300 局，模型偏乐观）：普通三角色 100%，困难 98~99%，平均清层 24~26s；当时仍有倒计时，现行无倒计时基线见 §15。

## 10. v3.3 调整（第三轮试玩反馈）

| 问题 | 处理 |
| --- | --- |
| 地图下方墙壁又出现了 | 不再用透明度渐隐（会触发材质重编译和闪烁），改成**相机退到哪侧就隐藏那面墙 + 压顶条**（`TowerFloor.setWallHidden`）；南/东等任意边都不会再挡视线 |
| 地板一直闪、眼睛难受 | 火把点光的高频抖动（9.3/17.1/21.7Hz）改成 1.6/0.9/2.3Hz 的缓慢呼吸，振幅从 ±16% 降到 ±5%，不再让地板亮度频闪 |
| 障碍物又变多 | 9 个场景道具数量再降约 35%（每层 8~14 个） |
| 想要休息隧道 | 新增 **休憩营地**（rest 房，权重 20%）：回血 28% + 充能 50%，不给金币；隧道四类权重改为奖励 32 / 交易 28 / 对战 20 / 休息 20 |
| 想要单层重试 | 每次进入新层都会存一份「层开局快照」；失败结算页新增 **重试本层** 按钮，回滚到本层血量/金币/背包/专武等级后重开本层 |
| 哥布林之王招数少 | 二阶段新增 **环形弹幕**：每 6.5 秒向 12 个方向各射一发紫色弹幕（配合原有砸地 + 召唤 + 冲锋） |
| 肥鱼专武收益低 | 小鲸子继承生命 35%→**55%**、伤害 40%→**60%**、攻击间隔 0.6→0.45s；召唤瞬间新增 **26 伤害 / 4.2m 冲击波**；白米饭间隔 10→8s、每层 +7% 全属性（上限 8 层），拾取时飘「白米饭 x/8」 |
| 白米饭看不到 | 米饭生成时加绿色光环 + 顶部提示「白米饭出现了！」，拾取后按层数实时加到面板 |

关于「流浪商人每次都出现」：**不是商人固定刷新**。v3 规则是每层清空 → 三选一卡 → 时空隧道三选一 → **固定进一次商店**（4 格货架+重掷）→ 下一层。商人是固定环节，隧道里的「流浪商人」房只是额外多开一次货架。

实现补充：商人房货架离开后仍进入本层标准商店；标准商店离开后才存档并进入下一层。`shopMode` 区分 `room`（额外货架）与 `standard`（标准商店），两者各只结算一次，不会形成无限商店循环。

## 13. 丛雨专武逐级收益（v3.7）

> 基础面板：生命 205 / 充能 80 / 耐力 145（约 0.38s 一刀）/ 魔力 95（实际伤害 ≈ 面板 ×0.95）/ 智力 70（扇形半径 = 3.4×0.7 ≈ 2.4m）/ 移速 7.5。
> 技能「居合突进」基础：突进 7.5m、路径宽 2.4m、45 伤害、落点聚怪 2.8m、0.4s 无敌、0.12s 硬直。

| 等级 | 价格 | 普攻 | 吸血 | 闪避 | 技能回血 | 其他 |
| --- | --- | --- | --- | --- | --- | --- |
| Lv1 | 免费 | 19 | 0 | 0 | 每命中 1 个敌人回 **7** | 充能 80 |
| Lv2 | 110 | **20** | **3%** | 0 | 每命中回 7 | **技能把路径敌人聚到落点**（取消普攻拉怪）；充能 76 |
| Lv3 | 190 | **21** | **5%** | **20%** | 每命中回 **9** | 充能 72 |
| Lv4 | 300 | **23** | **6%** | **22%** | 每命中回 **10** | 普攻附带 0.8m 前冲；技能伤害 +25%；充能 68 |
| Lv5 | 450 | **26** | **8%** | **25%** | 每命中回 **12** | 全属性 ×1.15、体型 +15%；充能 64 |

- **所有角色**闪避成功都会在头顶飘蓝色「闪避」+ 光环，不限丛雨。
- 技能回血 = 命中的敌人数 × 每命中回血量（命中越多回得越多，空技能不回血）。

## 15. v4.4 无倒计时 + 怪量微调（本轮）

- 移除 `timeLeft/timeLimit`、逐帧倒计时、超时判负和战斗房补时；失败只剩血量归零（`hp`）。
- 清层条件不变：非 Boss 层清完本层固定总数；Boss 层仍然只以哥布林之王死亡结算。
- HUD 原「倒计时」格改为「难度」标签；标题改为「一局约 8–12 分钟 · 清空每层 · 在血尽前登顶」。
- 怪量：`quotaBase 30→33`、`quotaPerLayer 7→7.5`；普通/困难仍 ×1.2、简单 ×0.9。普通整局总击杀约 +9%，各层约 +6~11%（困难第 15 层非 Boss 基础配额 166，Boss 层实际小怪 100，原 92）。
- 难度边界：没有提高小怪血量、伤害、移速或同屏上限，也没有改 Boss 血量；只增加总击杀数与相应的金币收入，避免同屏密度突然翻倍。

## 16. v4.5 背包扩容、金币训练与战斗反馈（本轮）

### 16.1 背包 12 → 18 格

- `balance.backpack.slots` 改为 **18**；`Inventory` 默认构造读取该值，并导出 `DEFAULT_BAG_SLOTS` 给 HUD 兜底。
- 背包仍是 4 列网格；矮屏（约 720p 及以下）时 `.inv-grid` 内部纵向滚动，避免第 5 行挤出面板。
- 合成规则不变：两张同级同种增益卡 → 下一级、数值 ×2，最高 tier3。

### 16.2 商店金币训练（后期金币出口）

- 每架商店固定 1 格 `kind='training'`，与专武/增益卡/消耗品共用 4 格；专武满级时由训练补位，保证不会出现「整架只剩卡」的空洞。
- 训练是**重复购买**条目：购买后不删格、不进背包，只更新价格与描述；`shopOffers` 不 splice。
- 数据：`balance.shop.training.stats`（魔力/耐力/智力/生命/移速/护甲/闪避/回能/暴击）；数值随层 `×(1 + valueGrowth×(层-1))`。
- 价格：`trainingPriceFor(layer, buys) = round(basePrice × (1 + layerGrowth×(层-1)) × priceGrowth^buys)`；默认 60 金、每层 +10%、每次购买 ×1.35。
- 进度存在 `RunState.training: Partial<Record<CardStat, number>>` 与 `RunState.trainingBuys`；`syncCards()` 把训练值并入卡牌面板，因此**不占背包也实际生效**。
- 跨商店累计：标准商店、商人房、重掷都会传当前 `trainingBuys`，所以价格不会因为换商店重置。
- 存档版本仍为 **3**；旧档没有 `training/trainingBuys` 时读档补空对象/0，不升版本、不删档。

### 16.3 小怪新增招式

| 单位 | 招式 | 前摇/范围 | 数值 | 冷却 |
| --- | --- | --- | --- | --- |
| 蛮兵 brute | 蓄力冲撞 | 0.5s 站定；锁定 8m 方向 | 速度 ×3.4，持续 0.38s；接触伤害照常 | 4.8s |
| 精英 elite | 锁定震地 | 0.72s 红圈；3.2m 半径 | 1.35× 接触伤害 | 5.2s |

- 冲撞/震地只在中距离触发（蛮兵 2.2~8.5m、精英 <6.2m），贴脸时不会突然起手。

### 16.4 Boss 后场沉睡与接触冷却

- Boss 生成点从 `-half×0.55` 后移到 **`-half×0.74`**（祭坛前），不再一进场就堵在入口。
- `GoblinKing.dormant = true` 时只做呼吸/朝向动画，不追击、不砸地、不召唤；玩家进入 **9.5m** 后 `setDormant(false)`，播放苏醒提示、音效和地面光环。
- 苏醒后砸地/冲锋冷却至少保留 1.2s/4s 的反应窗口。
- 身体接触伤害加 **0.9s** 冷却（`bossContactCd`），避免与 Boss 技能同帧叠加造成瞬秒。

### 16.5 地板闪烁收尾

- **不再**在墙/塔柱显隐时调用 `refreshShadow()`。阴影贴图保持静态，墙体只隐藏颜色网格；否则来回贴边会反复重算阴影，地面在「有影/无影」间跳。
- 地面纹理各向异性固定 **16x**（不再在 `floor.ts` 覆盖成 8x）；浮尘 40→22、尺寸 0.1→0.075、透明度 0.3→0.2，减少贴地看时的闪烁感。
- `freezeShadows()` 仍只在场景构建完成后执行一次。
