# 03 · 角色美术规格（按你给的参考图整理）

> 用途：作为像素图集（程序化 Canvas 或后续贴图）的绘制依据。数值见 `docs/02-角色数值设计.md`，数据见 `src/data/characters.ts`。
> 参考图对应关系：图 1/2/3 = 若叶睦与 Mortis，图 4/5 = 丛雨，图 6/7 = 蓝色大肥鱼。

## 0. 图集统一规格

沿用 `src/art/sprites.ts` 的「按方向分行、每实体独立 UV」方案，扩成 5 行 × 10 列：

| 行 | 方向 | 列（帧） | 说明 |
| --- | --- | --- | --- |
| 0 | 朝下 | idle A/B → run 1~4 → attack 1~3 → hurt | 主视角，细节最多 |
| 1 | 朝上 | 同上 | 背面，可省一半细节 |
| 2 | 朝左 | 同上 | 正面朝左，朝右由镜像复用 |
| 3 | 朝右 | 同上 | 可留空/镜像 |
| 4 | 技能态 | 变身/召唤/突进专用帧 | 若叶睦放 Mortis 帧，丛雨放拔刀帧，肥鱼放召唤帧 |

- 单元格 48×56（留出长发/帽子的溢出空间），脚底对齐 y=56。
- 描边：1px 深色（#1a1420 70% 透明），精灵本体 32~40px 高，保证 3D 场景里够醒目。
- 光照：不做方向性明暗，靠描边 + 高饱和色保证在任何火把光下可读。
- 所有角色共用 `NearestFilter`，禁止线性过滤（会糊）。

## 4. 动画与表现清单

| 状态 | 帧 | 时长 | 备注 |
| --- | --- | --- | --- |
| idle | 2 | 0.9s 循环 | 呼吸起伏 1px |
| run | 4 | 0.12s/帧 | 头发/裙摆滞后 1 帧 |
| attack | 3 | 与攻击间隔绑定 | 若叶睦投掷（手前推）；丛雨拔刀（前踏步）；肥鱼后坐+水枪抖动 |
| hurt | 1 | 0.12s | 整体闪白 + 后仰 1px |
| dash（丛雨技能） | 3 | 0.24s | 残影 3 个，刀光拉长 |
| transform（若叶睦） | 4 | 0.4s | 黑红烟雾 + 紫环炸开 → 切换 Mortis 图集 |
| summon（肥鱼） | 1 + 粒子 | 0.3s | 脚下水花环 + 3 只小肥鱼从水花里弹出 |

## 5. 待你确认的美术口径

1. 若叶睦的常态是不是**一直带着黄瓜**（还是只在攻击帧出现）？参考图里脚边有黄瓜，我倾向「攻击帧才出现，平时手空」。
2. Mortis 的乐器是**吉他**（图 3 攻击帧是吉他），但图 1 的技能图标画的是斧头——以吉他为准，对吧？
3. 丛雨的刀光是**蓝色水色**还是**纯白**？（图 5 是蓝色，图 4 偏白蓝）
4. 大肥鱼技能名：图 7 写作「蓝大鲨」，但效果是复制 3 只小肥鱼——技能名用「蓝大鲨」还是「召唤小肥鱼」？
5. 三角色同级配色已按图取定，是否需要**统一描边粗细与阴影色**（我建议统一 1px `#1a1420`，避免三人放在一起风格打架）。
